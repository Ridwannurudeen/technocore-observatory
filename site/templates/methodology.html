The Observatory separates stored evidence, derivation and publication. Each layer retains its own time, limits and version.

01 / TIME

Source, derivation, publication

source_observed_at belongs to the newest evidence used. derived_at records calculation time; published_at records release time. Validity is always source time plus fifteen minutes, so rebuilding frozen input cannot make it fresh.

02 / RULES 1.0.0

Three incident rules. No inferred cause.

health_probe_failed
A contiguous interval of unsuccessful /healthz observations, resolved by the next success.
endpoint_5xx
Observed HTTP 5xx attempts on one normalized route, resolved by the next successful attempt.
collector_gap
An interval beyond the declared cadence, resolved by the next accepted collector tick.

03 / EVIDENCE

Stored before interpreted

Accepted collector ticks support public-capacity and rate measurements. Normalized request attempts support reachability, latency and failure counts. Canonical discovery snapshots support allowlisted configuration diffs. Room evidence stays in the local index; static pages never publish a bulk name list.

04 / CEILING

What the record cannot establish

A successful probe is not an availability promise. A failed attempt is not an outage diagnosis. Unknown is not zero, and not observed is not absent. The ledger hash chain supports internal consistency only unless externally anchored.
